MM Animation Library - Examples

Basic Split Types

Lines Split

Split text into lines with basic fade animation (scroll-triggered)

In this example, the text is divided into individual lines, and each line is animated to fade into view sequentially when scrolled into view. The animation is designed to create a smooth and visually appealing transition, where each line appears one after the other with a slight delay.

data-splitting="lines" data-animate="fade-in" data-stagger="0.1" // Scroll-triggered by default with 0.2ms delay

Words Split

Split text into words with slide animation (scroll-triggered)

This text is split into words. Each word will slide up with a stagger effect when scrolled into view.

data-splitting="words" data-animate="slide" data-axis="y" data-stagger="0.05" // Scroll-triggered by default with 0.2ms delay

Characters Split

Split text into characters with fade animation (scroll-triggered by default)

This text is split into characters. Each character will fade with a stagger effect when scrolled into view.

data-splitting="chars" data-animate="fade-in" data-stagger="0.02" // Scroll-triggered by default with 0.2ms delay

Stagger Methods

Start Stagger

Animation starts from the beginning

This text animates from start to end.

data-stagger-method="start"

End Stagger

Animation starts from the end

This text animates from end to start.

data-stagger-method="end"

Center Stagger

Animation starts from the center

This text animates from the center outward.

data-stagger-method="center"

Random Stagger

Animation elements in random order

This text animates in random order.

data-stagger-method="random"

3D Animations

Basic 3D Rotation

Simple 3D rotation with default settings

This text rotates in 3D space with default settings.

data-animate="3D" data-rotation-x="-100" data-transform-origin="50% 50% -160px"

Custom 3D Perspective

3D rotation with custom perspective

This text has a deeper 3D perspective effect.

data-perspective="2000" data-rotation-x="-180" data-transform-origin="50% 50% -200px"

3D with Center Stagger

3D rotation with center stagger effect

This text rotates from the center outward in 3D space.

data-stagger-method="center" data-rotation-x="-90"

Easing Functions

Power Easing

Different power easing functions

Power1 easing - gentle acceleration

Power2 easing - moderate acceleration

Power3 easing - strong acceleration

data-easing="power1|power2|power3"

Special Easing

Special easing functions for unique effects

Back easing - overshoots the target

Elastic easing - bounces like a spring

Bounce easing - bounces at the end

data-easing="back|elastic|bounce"

Scroll Animations

Default Scroll Reveal

All animations are scroll-triggered by default with 0.2ms delay (no replay)

This text animates when scrolled into view (default behavior, no replay).

// No data-scroll-reveal needed - it's the default behavior // No data-revert needed - animations don't replay by default

Custom Scroll Reveal Delay

Custom delay when element comes into view

This text has a custom 0.5ms delay when scrolled into view.

data-scroll-reveal-value="0.5"

Disable Scroll Reveal

Animation plays immediately without scroll trigger

This text animates immediately without waiting for scroll.

data-scroll-reveal="false"

Enable Animation Replay

Animation replays when element leaves and re-enters viewport

This text replays the animation when scrolled out and back in.

data-revert="true"

Legacy Scroll Trigger

Animation with custom trigger points

This text animates between custom trigger points.

data-start="top center" data-end="bottom center"

Scrub Animation

Animation scrubs with scroll position

This text scrubs with the scroll position.

data-scrub="0.5"

Combined Effects

3D with Fade and Slide

Combining multiple animation types

This text combines 3D rotation with fade and slide effects.

data-animate="3D fade-in slide" data-stagger-method="center" data-duration="1.2"

Complex Scroll Animation

Complex animation with scroll trigger

This text combines multiple effects with scroll scrubbing.

data-animate="fade-in slide" data-scrub="0.5" data-stagger-method="random" data-easing="elastic"
